Principais Destaques da Análise

🖥️ Interface Gráfica (GUI)

A maioria dos artigos implementa interfaces gráficas com feedback visual em tempo real, exibindo texto, legendas ou animações de gestos reconhecidos.

🎮 Gamificação e Jogos Sérios

Trabalhos como Adventure ASL e ChessSIGN usam ambientes de jogo interativos para ensinar língua de sinais de forma engajante.

🌐 Interfaces Web e Formulários

Artigos como o de López et al. (2019) propõem questionários online em língua de sinais com vídeo, e Seita et al. (2025) desenvolvem formulários bilíngues ASL/Inglês.

🥽 Realidade Mista e Imersiva

Wen et al. (2024) propõem um ambiente de realidade mista para ensino de língua de sinais com feedback multidimensional, superando limitações de recursos 2D.

Sobre esta Análise

Este estudo analisa artigos exportados da base Scopus com o objetivo de identificar trabalhos que propuseram o desenvolvimento de interfaces digitais voltadas para línguas de sinais — seja para o ensino/aprendizagem de língua de sinais, seja para facilitar a comunicação de pessoas surdas ou com deficiência auditiva.

A análise distingue artigos que apenas desenvolveram algoritmos de reconhecimento de gestos (sem foco em interface de usuário ou aplicação educacional) daqueles que efetivamente propuseram e implementaram uma interface interativa destinada ao usuário final.

Critérios de Inclusão

Um artigo foi incluído na seleção se atendeu a pelo menos um dos seguintes critérios:

  • Propôs ou implementou uma interface gráfica de usuário (GUI) voltada para língua de sinais
  • Desenvolveu um aplicativo, sistema web ou plataforma para ensino ou comunicação em língua de sinais
  • Criou um jogo sério ou ambiente gamificado para aprendizagem de língua de sinais
  • Desenvolveu formulários, questionários ou ferramentas de avaliação acessíveis em língua de sinais
  • Propôs uma interface de realidade aumentada, mista ou virtual para ensino de língua de sinais
  • Implementou um assistente virtual ou avatar que comunica em língua de sinais
  • Desenvolveu uma ferramenta de edição de vídeo voltada para conteúdo em língua de sinais
  • Criou uma interface de comunicação bidirecional (texto/fala ↔ língua de sinais) para uso prático

Critérios de Exclusão

Foram excluídos artigos que:

  • Apenas propuseram algoritmos de reconhecimento de gestos sem interface de usuário final
  • Focaram exclusivamente em métricas de acurácia de classificação sem aplicação prática
  • Usaram língua de sinais apenas como exemplo de aplicação de técnica de machine learning genérica
  • Não tinham relação com acessibilidade ou comunicação de surdos como objetivo principal
