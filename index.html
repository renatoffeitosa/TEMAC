Metodologia da Pesquisa

Este estudo realizou uma análise sistemática de artigos científicos para identificar propostas de interfaces digitais voltadas para línguas de sinais. O foco não foi apenas o reconhecimento de gestos, mas a aplicação prática em interfaces de usuário (HCI).

Critérios de Inclusão:
  • Desenvolvimento de protótipos de interface (GUI, Web, Mobile).
  • Foco em Ensino de Língua de Sinais ou Facilitação da Comunicação.
  • Uso de tecnologias assistivas e feedback ao usuário.
